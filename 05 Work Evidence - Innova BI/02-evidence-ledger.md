**Confidence definitions.** *Confirmed* = the artifact directly demonstrates it and I read the
artifact. *Strongly Supported* = multiple independent artifacts point the same way. *Plausible* =
consistent with the evidence but a step of inference is required. *Unverified* = named in Joel's
own materials with no corroborating artifact.

**Attribution definitions.** *Authored* = the artifact's content, comments or naming show Joel
wrote it. *Led/Owned* = he specified, drove or is the named owner. *Contributed* = he worked on a
multi-author asset. *Team* = the organisation delivered it, his role unclear. *Present only* =
the file was in his possession; authorship not established.

**Résumé suitability.** *Safe* = usable as written. *Safe if rephrased* = true but the current
phrasing overstates. *Needs Joel* = see [[05-questions-for-joel]]. *Do not use.*
