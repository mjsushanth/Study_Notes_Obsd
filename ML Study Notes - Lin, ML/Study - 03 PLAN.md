

Machine Learning from a probabilistic perspective. 

Plan for topics:-
1. Introduction: Machine Learning, Supervised, Unsupervised and basics. 

Probability: Distributions, Transformations, Monte Carlo approximations, Information Theory. 

3. Generative Models: Bayesian Concept Learning, Beta-Binomial, Dirichlet Multinomial Model, Naive Bayes Classifiers.

4. Gaussian Models: GDA, Inference in Joint Gaussian, Linear Gaussians, Wishart, parameter inference. 

5. Bayesian Statistics: Posteriors, distributions, Bayesian Model Selection, Priors, 
Hierarchical, Empirical Bayes, Decision Theory.

6. Frequentist Statistics: Sampling, Frequentist decision theory, properties, Empirical Risk Minimization, Pathologies. 

7. Linear Regression: Model specification, MLE, Robust, Ridge, Bayesian Linear Regression.

8. Logistic Regression: Model Specification, fitting, Bayesian Regression, Online learning and stochastic optimization, classifiers. 

9. GLMs, Exponential family: Exponential family, GLMs, Probit, Multi task learning, Generalized GLMs, Rank. 

10. Directed Graphical Models: Examples, Inference, Learning, Conditional Independence, Influence diagrams.

11. Mixture Models, EM algorithm: 
Latent variable, Mixture, estimations,
EM algorithm, Model selection and fitting. 

12. Latent linear models: FA, PCA, latent dimensions, PCA for categorical, paired, multiview data, ICA.

13. Sparse Linear Models: Bayesian Variable selection, L1 regularisation, Non-convex regularizers, ARD, Sparse Coding.

14. Kernels: Kernels, Usage, tricks, SVM, comparisons, building generative models.

15. Gaussian Processes(GP): GPs for Regression, GLMs, relations, GP latent models, Approximations.

16. Adaptive basis function models: CART, Additive, Boosting, FNNs, Ensemble, Experimental Comparison, Interpreting models. 

17. Markov and Hidden Markov Models(HMM): Markov, HMM, Inference, Learning and Generalizations.

18: State Space Models: Applications, Inference, Learning for Linear Gaussian SSMs. Approximate Online inference, Hybrid SSMs.

19. Undirected Graphical Models: Conditional Indepedence, Parameterization, Examples, Learning, CRFs, Structural SVMs. 

20. Exact Inference: Belief propagation, Variable Elimination, Junction Tree, Intractability. 

21. Variational Inference: VI, Mean, structured mean field, Variational Bayes, EM, Message Passing, VIBES, Bounds, Loopy Belief, Expected propagation, MAP state estimators. 

22. Monte Carlo Markov Chains: Rejection, Importance sampling, Particle Filtering, RBPF, Gibbs, Metropolis Hastings, Annealing, approximations. 

23. Clustering: Dirichlet MM, Affinity, Spectral, Hierarchical, Clustering. 

24. Graphical Structure Learning: Knowledge discovery, Tree structures, Causal DAGs, learning. 

25. Latent linear models : LDA, LVMs, Restricted Boltzmann

26. Deep Learning: Generative, Deep Nets, Applications.
